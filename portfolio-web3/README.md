# Ahmed Seddik | Web3 Portfolio

A modern, professional portfolio website for Data Scientist, Software Developer, and Robotic Engineer Ahmed Seddik. Built with React, TailwindCSS, Vite, Framer Motion, and Web3 integration (ethers.js).

## 🚀 Features
- Hero section with CTAs
- About Me, Projects, Experience, Skills
- Web3 wallet login (MetaMask)
- Exclusive content for wallet holders
- Contact form
- Dark/Light mode toggle
- Responsive, animated, SEO optimized

## 🛠️ Setup
1. **Clone the repo:**
   ```sh
   git clone <repo-url>
   cd portfolio-web3
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Run locally:**
   ```sh
   npm run dev
   ```
4. **Edit content:**
   - Update info in `src/data/` and components as needed.
   - Add your CV/report to `public/assets/`.

## 🌐 Deployment
- Deploy to [Vercel](https://vercel.com/) or [Netlify](https://netlify.com/) for production.
